# Sistema de Administração de Funcionários

O programa permite administrar uma lista de funcionários através de um menu interativo, utilizando conceitos fundamentais de C++, como estruturas (`struct`), vetores dinâmicos (`std::vector`) e manipulação de strings.

## 🚀 Funcionalidades

O sistema oferece as seguintes operações:
* **Incluir:** Cadastra um novo funcionário (Prontuário, Nome e Salário). O sistema impede o cadastro de prontuários duplicados.
* **Excluir:** Remove um funcionário da lista através do seu prontuário.
* **Pesquisar:** Localiza um funcionário pelo prontuário e exibe seus dados detalhados.
* **Listar:** Exibe todos os funcionários cadastrados e, ao final, apresenta o somatório total de todos os salários.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** C++
* **Biblioteca Padrão:** `iostream`, `vector`, `string`, `iomanip` e `clocale`
* **IDE Recomendada:** Dev-C++ ou qualquer compilador compatível com C++

## 🔧 Como Executar

1. Clone o repositório ou baixe o arquivo `.cpp`.
2. Abra o arquivo em uma IDE (como o Dev-C++).
3. Compile e execute o código.
4. Utilize o menu numérico para navegar entre as funções.
